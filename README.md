# 🦎 Jurassic Feed

Application de suivi d'animaux de compagnie et d'élevage, pensée d'abord pour le smartphone : escargots, araignées, serpents, isopodes, mantes, scorpions, phasmes, lézards, amphibiens, mais aussi chiens, chats, oiseaux et rongeurs.

👉 **Utiliser l'application : https://mycslelahein.github.io/jurassic-feed/**

## Fonctions

- Fiches animaux : espèce, sexe, naissance, origine, acquisition, photo
- Journal : repas, eau, mues, poids, taille, nettoyage, santé, reproduction, température et humidité
- Rappels réguliers (tous les X jours ou certains jours de la semaine) et notifications
- Généalogie et lignées
- Agenda des mues, pontes et éclosions prévues
- Courbes et statistiques
- Fiches d'élevage conseillées par catégorie, modifiables
- Matériel et équipement
- Thème sombre ou clair

## Installation sur téléphone

Ouvre le lien ci-dessus dans Chrome (Android), puis menu ⋮ → **Installer l'application**. Elle s'ouvre ensuite comme une vraie application et fonctionne hors connexion.

## Tes données

- Elles sont enregistrées sur ton appareil et fonctionnent sans connexion.
- Avec la connexion Google, elles sont aussi synchronisées automatiquement dans un espace personnel (Firebase). Tu retrouves ton suivi sur tous tes appareils.
- Tu peux à tout moment faire une sauvegarde dans un fichier (Réglages → Sauvegarde).

Cette application est un projet personnel : les données de chaque utilisateur sont privées et ne sont lisibles que par son propre compte.

## Technique

Une seule page web (HTML, CSS et JavaScript), sans framework, installable (PWA) avec Firebase pour la synchronisation. Pour utiliser ta propre copie, remplace la configuration Firebase dans `index.html`.
